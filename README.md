# Flower Planets

Static website prepared for GitHub Pages.

## Publish

1. Create a GitHub repository and upload the files in this folder, including `.github/workflows/pages.yml` and all `frame_*.png`, `img*.jpeg`, and `logo.jpeg` assets.
2. In the repository, open **Settings > Pages** and set the build and deployment source to **GitHub Actions**.
3. Push to the `main` or `master` branch, or run **Deploy Flower Planets to GitHub Pages** from the Actions tab.

The workflow publishes the website as `index.html` and copies its local image assets into the Pages site.
